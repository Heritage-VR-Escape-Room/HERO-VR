## Notes

- Fritz (companion raven): the in-game bird is the CC-BY 'Crow' model credited above, driven by Fritz's own procedural motion for any clip the model lacks (`fly`, `perch`, `idle`, `caw`); until the model is attached the bird is a built-in low-poly primitive.
- The pyramid and the Schloss are built in code from the CC0 Poly Haven sandstone texture credited above; no third-party mesh. The plane trees reuse the linden model.
- Models were rescaled, re-pivoted, decimated where heavy and compressed (meshopt, WebP); otherwise unmodified.
- `public/credits.json` mirrors this file for the in-game Credits screen; both are generated by `tools/assets/make_credits.py`.

## Audio

All sound (footsteps, Fritz, the circuit panel, the jammer, bells, the dog, pigeons, ambience, theme music) is synthesized at runtime with the Web Audio API in `src/audio/`. No third-party audio files are used.
